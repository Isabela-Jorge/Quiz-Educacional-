# Quiz Integrador

Projeto desenvolvido como parte do curso Técnico em Desenvolvimento de Sistemas da ETEC.

## 📌 Sobre o projeto

O **Quiz Integrador** é um sistema de perguntas e respostas desenvolvido pelos alunos com o objetivo de aplicar, de forma integrada, os conhecimentos adquiridos durante o curso.

O projeto envolve diferentes áreas do desenvolvimento de software, incluindo **Frontend, Backend, Banco de Dados, Testes e Documentação**.

## 🎯 Objetivo

Desenvolver uma aplicação de quiz funcional, organizada e integrada, aplicando conceitos de desenvolvimento de sistemas, banco de dados, APIs, testes e documentação.

## 🛠️ Tecnologias

As tecnologias utilizadas no projeto serão definidas e documentadas ao longo do desenvolvimento.

* HTML
* CSS
* JavaScript
* [Frontend]
* [Backend]
* [Banco de Dados]

## 🌿 Organização do Git

O projeto utiliza Git e GitHub para controle de versão.

### Branches principais

* `main` — versão estável do projeto
* `develop` — branch utilizada para integração do desenvolvimento

As funcionalidades serão desenvolvidas em branches específicas e posteriormente integradas à `develop` por meio de Pull Requests.

Exemplo:

```text
develop
   │
   ├── feature/login
   ├── feature/quiz
   ├── feature/ranking
   └── feature/api-questoes
```

## 👥 Equipes

O projeto é dividido em equipes responsáveis por diferentes áreas:

* **Frontend** — desenvolvimento da interface
* **Backend** — desenvolvimento da lógica e APIs
* **Banco de Dados** — modelagem e gerenciamento dos dados
* **Testes** — validação e testes do sistema
* **Documentação** — documentação e registros do projeto

## 📋 Desenvolvimento

As tarefas serão organizadas por meio de Issues e acompanhadas pela equipe durante o desenvolvimento.

### Fluxo de desenvolvimento

```text
Issue
  ↓
Branch da funcionalidade
  ↓
Desenvolvimento
  ↓
Commit
  ↓
Pull Request
  ↓
Revisão
  ↓
develop
  ↓
main
```
