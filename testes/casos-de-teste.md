CT-XX – Limite de caracteres da senha

- Objetivo: verificar se o campo de senha respeita o limite máximo de caracteres definido pelo sistema.
- Entrada: inserir uma senha com quantidade de caracteres superior ao limite permitido.
- Resultado esperado: o sistema deve impedir caracteres adicionais ou informar que a senha ultrapassou o limite permitido.

---------------------------------

CT-XX – Senha contendo espaços

- Objetivo: verificar o comportamento do sistema ao inserir espaços no campo de senha.
- Entrada: inserir uma senha contendo espaços entre os caracteres.
- Resultado esperado: o sistema deve aceitar ou rejeitar a senha de acordo com a regra definida nos requisitos.

----------------------------------

CT-XX – Senha contendo emojis

- Objetivo: verificar o comportamento do sistema ao inserir emojis no campo de senha.
- Entrada: inserir uma senha contendo um ou mais emojis.
- Resultado esperado: o sistema deve aceitar ou rejeitar emojis de acordo com a regra definida nos requisitos.

-------------------------------------

CT-XX – E-mail em formato inválido

- Objetivo: verificar se o sistema rejeita endereços de e-mail que não possuem um formato válido.
- Entrada: "@G" e "a@g"
- Resultado esperado: o sistema deve informar que o e-mail é inválido e impedir o envio do formulário.
