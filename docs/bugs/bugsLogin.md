BUG-001 – Campo de "nome completo" aceita numeros
- Tela: Cadastro/Login
- Problema: É possível criar uma conta contendo numeros no campo de "Nome Completo".
- Esperado: O sistema deve rejeitar Nomes contendo numeros.
- Atual: O sistema aceita numeros no campo de "Nome completo" como válidos.
