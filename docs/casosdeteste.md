CT-XX – E-mail contendo simbolos além do "@"

- Objetivo: verificar se o sistema rejeita endereços de e-mail que possuem simbolos além do "@".
- Entrada: inserir um e-mail contendo simbolos antes do "@"
- Resultado esperado: o sistema deve informar que o e-mail é inválido e impedir o envio do formulário.

CT-XX – Nome de usuario contendo emojis

- Objetivo: verificar o comportamento do sistema ao inserir emojis no campo de nome de usuario.
- Entrada: inserir um nome de usuario contendo um ou mais emojis.
- Resultado esperado: o sistema deve rejeitar emojis de acordo com a regra definida nos requisitos.
